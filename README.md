# Asistent učiteľa

Webstránka s nástrojmi pre učiteľov na každý deň. Funguje v prehliadači, netreba nič inštalovať.

## Čo obsahuje

- **Kalendár školského roka 2026/2027:** prázdniny (aj jarné podľa krajov), maturity, Testovanie 9, prijímacie skúšky a vlastné termíny
- **Meniny:** kto má meniny dnes a kto zajtra
- **Citát dňa:** každý deň iný citát o vzdelávaní, výchove, psychológii a vede
- **Kalkulačka** so zátvorkami, percentami a históriou výpočtov
- **Generátor náhodných čísel:** ľubovoľné číslo alebo vlastné rozpätie
- **Losovanie mien a slov,** voliteľne bez opakovania
- **Rozdelenie do skupín** podľa počtu skupín alebo počtu členov
- **Prevod jednotiek:** dĺžka, hmotnosť, objem, plocha, čas, rýchlosť, teplota, dáta
- **Hod mincou** s vlastnými možnosťami
- **Časovač** so zvukovým signálom a **stopky** s medzičasmi
- **Hlukomer:** meria hluk v triede mikrofónom; mačka Micka spí, kým je ticho, a pri hluku sa zobúdza až rozčúli (mikrofón funguje cez https alebo pri otvorení súboru, zvuk sa nikam neodosiela)

Väčšinu nástrojov je možné zobraziť na celú obrazovku, napríklad pre projektor.

## Spustenie

Otvorte súbor `index.html` v prehliadači, alebo zapnite GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).

## Upozornenie

Termíny v kalendári vychádzajú zo zverejneného harmonogramu MŠVVaM SR pre školský rok 2026/2027. Pred dôležitým plánovaním ich overte na [minedu.sk](https://www.minedu.sk).
